Notion In Notion, create an internal integration, copy its secret, open the target page → ⋯ → Connect to / Add connections → pick that integration. Paste the secret and the page link (Copy link). Under Capabilities, enable Update content and Insert content (read-only lets you inspect but not sync). Sync replaces that page's blocks; images upload to Notion. Large PDFs: the JSON can exceed reverse-proxy limits (nginx client_max_body_size). Use Text only — skip images if export fails with 413 or a generic network error.
